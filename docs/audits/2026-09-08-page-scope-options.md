# MVP 페이지 범위 선택지 — 2026-09-08

상태: **제품 방향 사용자 확정 / 페이지 처분은 제안·미결 구분**. 코드 읽기만 수행하고 이 문서만 작성했다. 경로 이동·제품 코드 변경·브라우저·테스트 없음. 경로에는 `/ko` 또는 `/en`이 앞에 붙는다.

## 결정 수준

| 구분 | 내용 |

기존 감사의 **정보12종 분류는 코드 현황 집계**다. 여기에 용어를 포함하면 정보/보조 화면 후보는 **13종**, 편성·추천은 2종이 된다. 이는 새 범위 확정 숫자가 아니라 ops 유지 제안을 반영한 후보 집계다.

앞선 감사의 정보12종/새 디자인6·구판6 분류 승인은 페이지 제외 결정이 아니다. 특히 **용어는 정보 보조 화면**으로 편성·추천과 별도로 판단한다. 9월 7일 scope-reset의 일괄 `/lab` 이전은 현행 사실이나 확정 처분으로 사용하지 않는다.

공통 헤더의 홈/언어 전환과 footer 링크는 모든 페이지에 적용된다. 언어 전환은 경로 첫 세그먼트만 바꾸므로 이동을 선택하면 ko/en 경로를 함께 다뤄야 한다.

## ops가 순차 결정할 때 구분할 것

- **유지:** 현 URL과 진입점을 유지. 구판 디자인 여부와 별개 결정.
- **메뉴 숨김:** 페이지는 현 URL에서 계속 동작. 홈 카드·footer도 숨길지는 별도 명시; 접근 차단이 아님.
- **실험실 이동:** 현 URL 변경. nav/홈뿐 아니라 자기 링크·페이지 이동 경로, 기존 주소 리다이렉트 여부도 결정.
- **삭제:** 화면 접근 자체를 없앰. 연결 링크와 제공 정보의 대체 위치 검토가 필요하며 공유 데이터/엔진까지 삭제한다는 뜻은 아님.

제안 순서: 편성 → 추천 → **용어 유지 제안의 노출 방식 결정** → 던전 → 층 → 고지. 이 순서는 범위 대화 순서이며 네 핵심 엔티티의 우선순위 차등이 아니다. 표의 유지/숨김/이동/삭제 대안은 사용자·ops가 각 페이지 처분을 확정하기 전에는 실행하지 않는다.
