# 2026-11-23 클라이언트·ETL 작업 정리

이 문서는 2026-09-08 이후 로컬에서 진행한 작업의 최종 상태를 기록한다. 이전 시안 문서와 충돌할 경우 이 문서의 확정 사항을 우선한다.

## 클라이언트

- 문서 질감을 유지한 공통 디자인 토큰, 밝은/어두운 테마, 시스템 테마 기본값 및 브라우저 선택 저장.
- 인격·E.G.O·기프트·팩 목록과 상세에 공통 컴포넌트, 게임 UI 대표 아이콘, 로딩·오류 화면 적용.
- 목록 제목 아래 검색/필터를 배치하고, 로딩 중에도 필터 공간과 이미지 비율을 예약.
- 한글 완성 글자 1개 또는 초성 2개부터 자동 검색. IME 조합 중 보류, 디바운스, 인격/E.G.O 목록의 로컬 검색 및 서버 참고 데이터 캐시. 필터는 적용 버튼으로 확정.
- 인격: 수감자별 기본 인격 우선 → 성급 오름차순 → 출시일 오름차순 → 이름.
- E.G.O: 수감자별 기본 E.G.O 우선 → 출시일 오름차순 → 이름. 등급은 장착 슬롯 구분이며 정렬 우선순위에 사용하지 않는다.
- 기프트 성위 내림차순은 별도 유지.
- 상세 최종 배치: PC에서 식별 정보 좌측·일러스트 우측, 단계 선택·능력치·스킬은 하단 전체 폭. 모바일은 이미지 → 식별 정보 → 데이터 순. 본문 좌측 정렬 유지.
- 전체 일러스트 원본 비율 보존, 로딩 크기 예약, 디코딩 후 이미지 전환. E.G.O 침식은 확보된 프로필만 사용하며 미확보 전체 CG를 지어내지 않는다.
- 상단 메뉴 방문은 목록 스크롤 초기화, 상세와 목록 왕복은 검색/필터/위치 보존.
- 키워드 아이콘과 인접 설명 팝업, 코인 효과별 아이콘·간격, 관련 정보 미리보기.
- 홈: 진행 중 픽업·이벤트, 현재 시즌과 시즌 이미지, 거울 던전 이름. 거울 던전 입구 이미지와 테마 팩 미리보기는 최종적으로 제거.

- 기존 DB 복구: `npx tsx --env-file-if-exists=.env scripts/repair/ego-stage-localization.ts`로 감사, `--apply`로 트랜잭션 복구. 두 번째 감사에서 추가 복구 0행 확인.

## 복원 및 운영

1. `npm ci`, `.env.example`을 참고하여 로컬 `.env` 설정.
2. README의 DB/Prisma 생성·스키마·ETL 초기화 절차 수행. 기존 DB에 nullable 팩 스키마 변경이 필요하면 `scripts/update/mirror.mts`의 명시적 ALTER 적용 경로를 확인한다.
3. 게임 원천 데이터 및 전체 어셋은 기존 fetch/assets/update 파이프라인으로 복원한다. DB 자체와 원천 스냅샷은 Git 푸시 대상이 아니다.
4. 홈 배너·대표 아이콘은 `node scripts/restore-ui-assets.mjs`로 복원. `content/ui-assets.json`에 고정된 출처와 SHA256을 검증한다.
5. `npm run dev -- --hostname 127.0.0.1 --port 3100`.

게임 원천·수집 결과·스크린샷·브라우저 자동화 임시 도구·과거 시안 빌드는 `var/`에 로컬 보존한다. 추천 엔진 외부 원문은 `references/limbus-ing/2026-11-22/`에 로컬 보존하고, 원격에는 출처 manifest와 설명만 포함한다. 해당 엔진이 제품에 통합됐다고 간주하지 않는다. 자체 브랜드와 무료 폰트는 라이선스와 함께 추적한다.
