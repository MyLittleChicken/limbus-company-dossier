# 하드 난이도 전용 기프트를 한 출처만 보고 적재한다

> 상태: **신규 DB 에서 해소** · ~~현행 DB 는 미착수~~ **현행 소멸** (2026-08-09 · PR #28) / 확인 2026-07-31
> 데이터 마스터북 기프트 편 회차 1(`limbus-data-mj/gifts.json`)에서 확인했다.

## 0. 신규 3스키마 DB 에서는 해소됐다 (2026-07-31)

`canonical.gift.hardOnly` 를 합집합으로 적재한다.

```ts
// src/v2/canonical/gifts.ts
const hardOnly = bool(mj, 'hardOnly') || bool(a, 'hardonly');
meta.source('gift', id, 'hardOnly', 'union', [MJ, ASSETS]);
```

검증이 이 값을 지킨다 — `npm run v2:verify:canonical` 의
「hardOnly true (합집합 122)」 검사. 판정 근거는 `canonical.field_source` 에
`rule = 'union'` 으로 남는다.

**현행 `public` 스키마(`src/entities/gifts.ts:107`)는 그대로다.** 신규 DB 와
병존 중이며 전환 시점에 함께 정리한다. 아래는 그 판정 기록이다.

## 1. 증상

`Gift.hardOnly` 를 `limbus-assets` 만 보고 채운다.

```ts
// src/entities/gifts.ts:107
hardOnly: g.hardonly === true,
```

**두 출처가 서로 다른 것을 놓치고 있어, 한쪽만 쓰면 6건이 빠진다.**

```
mj hardOnly true       53
assets hardonly true  116
교집합 47 · mj 단독 6 · assets 단독 69 · 합집합 122
```

## 2. 게임으로 확인한 것

**다섯 건**을 게임 화면과 대조했고 **전부 하드 난이도 전용**이었다.

| id | 기프트 | 게임 | mj | assets |
| --- | --- | --- | --- | --- |
| `9226` | 누군가의 푸른 검 | 하드 · '검과 작품' 한정 | `false` ✗ | `true` ✓ |
| `9211` | 먹장구름 | 하드 · '가라앉은 우울'·'침잠쇄도' 한정 | `false` ✗ | `true` ✓ |
| `9212` | 모든 악의 끝 | 하드 · '기어오는 심연' 한정 · 합성 | `true` ✓ | 없음 ✗ |
| `9249` | 조그맣고 근사한 바이올린 | 하드 · '우.미.다'·'저택의 부산물' 한정 · 합성 | `true` ✓ | 없음 ✗ |
| `9841` | C형 정리 요원 장비 세트 | 하드 · '워프특급 살인사건 BokGak' 한정 · 합성 | `true` ✓ | 없음 ✗ |

**어느 한쪽도 완전하지 않다.** mj 단독 6건 중 **3건을 게임으로 확인했고 전부 하드**였다.

## 3. mj 만 아는 6건

지금 `false` 로 적재되고 있다.

```
9212  모든 악의 끝            tier 4 · poise
9249  조그맣고 근사한 바이올린   tier 4
9427  마을을 지킬 작살         tier 2
9428  고래의 심장             tier 4 · poise
9431  부서진 바이올린          tier 3
9841  C형 정리 요원 장비 세트   tier 4 · charge
```

**6건 중 5건이 서로의 합성 재료거나 결과물**이다.

```
9427 마을을 지킬 작살  +  9428 고래의 심장             →  9212 모든 악의 끝
9706  +  9707 반짝이는 폐품  +  9431 부서진 바이올린    →  9249 조그맣고 근사한 바이올린
```

**하드 전용 합성 계통 둘이 통째로 누락된다.** 재료와 결과가 함께 빠져 있어
합성 화면에서 계통 자체가 사라진다.

## 4. 왜 이렇게 갈렸나

불일치 65건이 **후기 id 대역에만 몰려 있다.**

```
불일치 있는 대역   92xx 25 · 97xx 14 · 98xx 15 · 94xx 5
불일치 0인 대역    90xx · 91xx
```

두 출처가 서로 다른 시점에 갱신을 놓친 것으로 보인다. 어느 쪽이 더 최신이라고
말할 수 없다 — 양방향으로 샌다.

## 5. 결정 — 합집합으로 적재한다 (2026-07-31)

게임 확인 5건이 전부 하드였고 **양쪽이 서로 다른 것을 놓친다**는 것이 확정됐다. `hardOnly` 는 "하드에서만 나온다"는 배타 조건이므로,
한쪽이라도 그렇게 말하면 참으로 두는 편이 안전하다. 반대로 두면 하드 전용을
일반 목록에 노출한다.

```ts
const mjHard = mj.get(id)?.hardOnly === true;
hardOnly: g.hardonly === true || mjHard,
```

`src/verify.ts` 에 **두 출처가 어긋나는 건수**를 리포트로 올려, 다음 스냅샷에서
줄어드는지 보는 것도 함께 한다(`docs/backlog/07-report-artifact.md` 와 같은 계열).

## 6. 미룬 이유

데이터 의미가 아니라 적재 결정이다. 마스터북 기프트 편(회차 1–8) 진행 중에 변환기를
건드리면 회차가 끊긴다. 편을 마친 뒤 코드 작업을 모아서 처리한다.
