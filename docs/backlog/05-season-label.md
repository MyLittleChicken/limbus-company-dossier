# 시즌 값이 화면에 원본 정수 그대로 나간다

> 상태: 미착수 / 확인 2026-07-29
> 데이터 마스터북 회차 1(`limbus-data-mj/identities.json`) 인터뷰에서 확인했다.

## 1. 증상

인격 목록 카드의 시즌 태그가 `S{season}` 이라 발푸르기스의 밤 인격 17건이 이렇게 뜬다.

```
S9101  S9102  S9103  S9104  S9105  S9106  S9107  S9108  S9109
```

게임에 없는 표기다. 통상 인격도 `S0` 으로 나가는데, 게임은 이것을 시즌 0이 아니라
**통상**이라 부른다.

| 위치 | 코드 |
| --- | --- |
| 목록 카드 태그 | `app/[locale]/identities/page.tsx:103` — `<span className="tag">S{i.season}</span>` |
| 상세 스탯 행 | `app/[locale]/identities/[id]/page.tsx:107` — `[ko ? '시즌' : 'Season', identity.season]` |

## 2. 값의 축이 둘이다

`identity.season` 한 컬럼에 **성격이 다른 두 종류의 수**가 들어 있다.

| 값 | 뜻 | 건수 |
| --- | --- | --- |
| `0` | 통상 인격 (시즌 미포함) | 65 |
| `1`–`7` | 시즌 번호. 7이 진행 중 | 100 |
| `9101`–`9109` | 발푸르기스의 밤 1–9회차 | 17 |

결손 2건(`10311` · `10708`)은 보강 출처의 `0` 으로 채워진다.

크기 비교·정렬·범위 필터가 성립하지 않는다. `season < 8` 같은 조건이 발푸르기스를
통째로 포함하거나 배제한다.

## 3. 표기 규칙

발푸르기스 값은 `91` 프리픽스와 2자리 회차로 분해된다. 실측 9101–9109가 전부 이 규칙을
따르며, 회차 10 이상이 와도 `9110` → 10회로 확장된다.

```
season = 0        → 통상
season = 1..7     → 시즌 N
season = 91NN     → 발푸르기스 NN회
```

파생 값이므로 **DB에는 원본 정수를 그대로 두고 화면에서만 변환한다**(02-data-model 원칙 2).
`seasonLabel(season, locale)` 하나를 두면 두 화면이 함께 해결된다.

## 4. 미룬 이유

데이터 의미가 아니라 화면 결정이다. 마스터북 인격 편(회차 1–14) 진행 중에 화면 코드를
건드리면 인터뷰가 끊긴다. 인격 편을 마친 뒤 화면 작업을 모아서 처리한다.

## 5. 남은 결정

- 영문 레이블: `Standard` / `Permanent` / `Base` 중 무엇으로 할지
- 발푸르기스 영문: `Walpurgis 4` / `Walpurgis Night 4`
- 목록 태그가 짧아야 하므로 상세와 다른 표기를 쓸지
