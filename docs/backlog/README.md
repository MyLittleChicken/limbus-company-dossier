# 백로그 (Backlog)

> 확인했으나 지금 단계에서 처리하지 않기로 한 것을 남긴다.

`docs/adr/`가 **내린 결정**을 기록한다면 여기는 **미룬 일**을 기록한다.
두 곳 모두 목적이 같다 — 판단의 근거를 잃지 않는 것이다.

미룬 일을 적지 않으면 나중에 근거를 다시 파야 한다. 조사에 든 시간이 그때 다시 든다.
따라서 **무엇을 미뤘는가보다 왜 미뤄도 되는가와 무엇을 알아냈는가**를 중심으로 적는다.

## 규칙

1. **처리한 항목의 파일을 지우지 않는다.** 상태를 바꾸고 처리 시점과 실제로 한 일을 덧붙인다.
   지운 기록은 "왜 그렇게 했는가"를 묻는 다음 사람에게 남지 않는다.
2. **실측을 적는다.** "많다"가 아니라 개수를 적고, 그 수를 어떻게 얻었는지 적는다.
3. **되돌리기 어려운 결정은 여기 두지 않는다.** 그것은 ADR의 몫이다.
4. **미룬 이유를 적는다.** 이유가 없으면 그것은 백로그가 아니라 누락이다.
5. **이미 다른 문서에 있는 것을 다시 적지 않는다.** 단계 문서와 ADR의 미결 항목이 먼저다.
   여기에는 그 어느 쪽에도 자리가 없는 것, 즉 조사 결과가 통째로 사라질 것만 남긴다.
6. **결정한 것을 미결로 적지 않는다.** 하지 않기로 한 일은 구멍이 아니다.
