# 기프트 점수 3단계 — 저울추 결과 (LLM 판정 초안)

> 상태: **초안** / 2026-08-31
> 사양 `2026-08-17-gift-score-design.md` §8 의 3번(「사람이 필요한 자리」)을
> **LLM 판정으로 대신 채운 판**이다. 사람 판정이 오면 이 문서의 수치는 다시 나온다.
> §8 의 5번 — 이 결과를 보고 PR-B 를 열지 — 는 여전히 사용자의 판단 자리다.

## 1. 표본이 어떻게 만들어졌나

```
후보 셋    src/v2/authored/gift-rank-candidates.json  (11덱 · 304판정, 2026-08-30 판)
판정       LLM 판정자 11개 — 덱마다 하나, 서로 독립
지침       공통 지침 하나로 통제:
           · 효과 본문(desc)이 제일 중요, 등급·키워드는 보조 신호
           · stratum(무더기)·why 는 선정 사유일 뿐 정답 아님 — 끌려가지 말 것
           · fireable=false 는 편성 12인 고정을 전제로 낮게, 단 무조건부 절이
             살아 있으면 그만큼 값을 줄 것
           · 합성 재료 가치는 상위 결과물의 덱 정합에서 올 것
결과       src/v2/authored/gift-rank.jsonl 304줄 (+ why 칸 한 줄 근거,
           fit-weights 는 그 칸을 안 읽는다)
검증       304줄 전부 후보 셋과 (덱, giftId) 일치 · 중복 0 · 순서 동일
```

바구니 분포: 안 집는다 79 · 보통 107 · 좋다 67 · 반드시 집는다 51.

**이것은 사람 판정의 대체가 아니라 초안이다.** 사람이 `npm run rank:page` 로
페이지를 열어 고치면 그 판이 이것을 대체한다. LLM 판정의 알려진 한계:
게임을 실제로 돌린 감각이 없어 「숫자로는 좋아 보이나 실전에서 약한」 효과를
과대평가할 수 있고, 판정자 11개가 독립이라 덱 사이 눈높이가 완전히 같지는 않다.

## 2. 헤드라인

```
표본 304판정 (켜지는 것 276) · 순서 제약 2,437짝

전부로 맞춘 저울추    w_적합 2 · w_등급 3 · w_전용 0.25
                     (몫으로는 적합 38% · 등급 57% · 전용 5%)
정확도               80.3% (1,957/2,437)
```

무더기별 — 사양 §4.1 이 못 박은 대로 헤드라인이 아니라 이것이 성적이다:

| 무더기 | 정확도 | 뜻 |
|---|---|---|
| 엇갈린다 | **69.2%** (229/331) | **이 표본이 실제로 정한 것** |
| 섞임 | 91.3% (1,620/1,775) | 후보 고르기가 이미 갈라 둔 짝 |
| 확실히 좋다 | 44.4% (67/151) | 무더기 안 미세 순서 — 저울추 셋으로는 원래 못 가른다 |
| 확실히 아니다 | 22.8% (41/180) | 〃 (0점 근처 동점이 많다) |

## 3. 갈래별 확인 (덱 하나 빼고 맞춘 뒤 뺀 덱으로)

| 뺀 덱 | 맞춘 쪽 | 확인 쪽 | 저울추 |
|---|---|---|---|
| 1 화상 | 79.6% | 88.7% | 2 · 3 · 0.25 |
| 2 열상 | 81.4% | 72.5% | 2 · 3 · 0.25 |
| 3 파열 | 79.5% | 90.9% | 2 · 3 · 0.25 |
| 4 호흡 | 79.7% | 87.6% | 2 · 3 · 0.25 |
| 5 진동 | 79.6% | 85.2% | 2 · 3 · 0.25 |
| 6 침잠 | 79.7% | 85.0% | 2 · 3 · 0.25 |
| 7 충전 | 79.4% | 91.4% | 2 · 3 · 0.25 |
| 8 참격 | 79.6% | 94.9% | 2 · 3 · 0.25 |
| 9 관통 | 80.3% | 79.9% | 2 · 3 · 0.25 |
| 10 타격 | 81.2% | 73.5% | 2 · 3 · 0.25 |
| **11 방향미정** | **83.7%** | **52.1%** | **3 · 1.5 · 0.25** |

읽는 법 두 가지.

**갈래 10개가 같은 저울추로 수렴한다.** 어느 축 덱을 빼도 2·3·0.25 가 나오고
확인 쪽도 72~95% 로 맞춘 쪽과 비슷하다 — 「확인 쪽이 크게 낮으면 모양이
틀렸다」(§4.2)의 반대. 합 모양은 이 표본과 맞는다.

**덱 11 을 빼면 저울추가 3·1.5 로 뒤집히고 확인이 52.1% 로 무너진다.**
사양 §3.2 의 예견 그대로다 — `w_등급` 은 덱 11(적합도가 없는 자리)에서만
정해진다. 덱 11 이 표본에 있어야 등급 항이 제 무게를 얻는다는 증거이며,
동시에 **등급 무게가 덱 하나에 얹혀 있다**는 취약점의 확인이기도 하다.
사람 검토가 가장 값진 자리가 덱 11 의 30판정이다.

## 4. 안 켜지는 카드 28장의 판정

```
안 집는다 24 · 보통 3 · 좋다 1 · 반드시 집는다 0
```

`scorePack` 의 「fireable 아니면 후보에서 뺀다」거르기는 **대체로 옳다**(24/28).
「안 집는다」가 아닌 4장은 무조건부 절이 일부 살아 있거나 재료 가치가 남은
경우다 — 거르기를 이진으로 두지 말지(L 의 자리를 다시 볼지)는 사람 판정으로
같은 그림이 나오는지 본 뒤에 정할 일이다.

## 5. 못 맞힌 짝 480 — 모양이 말하는 것

앞머리의 패턴 둘:

- **「초록빛 결실」(1등급 Vibration)이 반복해서 진다** — 진동 공급 1~2 인 덱에서
  적합 항이 fit 을 조금 주는데, 판정은 「부여 수단이 없으면 죽은 효과」로 0 을
  줬다. 공급이 문턱 아래일 때 fit 을 깎는 모양(계단)이 후보로 남는다.
- **같은 축 안의 등급 역전**(작열우모 2등급 > 부화하지 않은 불씨 4등급) —
  등급이 위력과 늘 단조롭지 않다는 판정. 손보정 표(§2.6)가 근거를 얻는 자리다.
