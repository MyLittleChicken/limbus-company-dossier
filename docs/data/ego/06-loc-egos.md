## 파일 정체

게임 클라이언트의 로컬라이즈 파일이다. 인격 편 회차 11–13과 같은 구조다.

```
최상위      { "dataList": [ … ] }
항목 키     id · name · desc      (3종. 로케일 3종 모두 동일)

Egos.json            110건    E.G.O 표시명·설명
Egos-a1c9p3.json       5건    델타 — 연출 전용 E.G.O
```

**세 로케일의 id 집합이 완전히 같다.** 본편 110건은 `egos.json` 과 집합이 일치한다.

| `loc-en` ↔ assets `name` | **110/110 일치** |

### mj 의 `nameKo` 결손 2건을 loc-ko 가 덮는다

```
20703 히스클리프 AEDD    mj nameKo: null    loc-ko: "AEDD"
21204 그레고르   AEDD    mj nameKo: null    loc-ko: "AEDD"
```

회차 1의 판정이 확인된다 — **결손이 아니라 한국어명이 영문과 같은 것**이다. 변환기의
폴백(`mj.nameKo ?? loc-ko ?? assets.name`)이 정확히 이 경우를 위해 있다.

### 이름 중복은 로케일과 무관하다

```
3로케일 전부   유일 73종 · 중복 32종
```

회차 1에서 본 영문 32종 중복이 한국어·일본어에서도 그대로다. **E.G.O 이름은 어느
언어에서도 식별자가 아니다.**

### 한자 병기는 대괄호로 쓴다

```
ko/en   즉저살 [蝍蛆殺] · 오혈읍루 [汚血泣淚] · 영작오 [宁作吾]

ja      대괄호 없음 — 한자를 본문에 그대로 쓴다
```

인격 편 회차 3의 `[[FirePunchFuel]` 같은 **마크업 오타가 아니다.** 정상 표기이며
`stripMarkup` 이 지워서는 안 되는 대괄호다.

**적재** — `EgoText.name`(`src/entities/egos.ts:107`).

## 2. `desc` — 정형 한 줄

내용이 없다. **수감자 이름 + 분류**로 만든 기계적 문장이다.

```
ko   "이상의 기본 EGO 장비"      "히스클리프의 전용 EGO 장비"
en   "Yi Sang’s Base E.G.O"      "Heathcliff’s E.G.O Gear"
ja   "イサン 基本E.G.O装備"      "ヒースクリフ 専用E.G.O装備"
```

### 「기본」이 정확히 12건이다

```
ko    기본 12 · 전용 98
en    Base 12 · E.G.O Gear 98
ja    基本 13 · 専用 97          ← 하나 많다
```

ko·en 의 「기본」 12건은 **전부 `slotId: 1` ZAYIN** 이다. 회차 1·2·3·4에서 나온
그 집합이 **다섯 번째로** 같다.

| 회차 | 같은 12건 |
| --- | --- |
| 1 | `slotId: 1` · ZAYIN |
| 2 | `corrosionSkill: null` |
| 3 | `corrosionType` 결손 |
| 4 | `erosion` 대사 0건 |
| 5 | `corrosionSkills` 그룹 0개 |
| **6** | **desc 가 「기본」** |

### 함정 — 일본어 `20302` 가 「基本」으로 잘못 적혀 있다

```
20302 물주머니 (돈키호테 · HE · slotId 2)

ko   "돈키호테 전용 EGO 장비"
en   "Don Quixote’s E.G.O Gear"
ja   "ドンキホーテ 基本E.G.O装備"      ← 기본이 아니다
```

`slotId` 가 2이고 등급이 HE 이므로 기본 E.G.O 가 아니다. **일본어 로케일 단독 오류다.**
`desc` 로 기본 여부를 판정하면 일본어에서 13건이 나온다.

### 한국어만 「EGO」로 쓴다

```
ko    EGO      110/110
en    E.G.O    110/110
ja    E.G.O    110/110
```

게임 UI 는 「E.G.O」를 쓰므로 **한국어 `desc` 의 표기가 흔들린 것**이다. 다만 이
문장 자체를 화면에 쓰지 않으므로 영향은 없다.

**적재** — 하지 않는다. 정보가 `sinnerId` + `rarity` 로 이미 있다.

## 3. `Egos-a1c9p3.json` — 연출 전용 E.G.O 5건

델타 파일이며 **본편에 없는 id 5개**를 새로 만든다.

```
201011  오감도              이상 연출 전용 EGO 장비
203011  라 샹그레 데 산쵸    돈키호테 연출 전용 EGO 장비
205011  타인의 사슬          뫼르소 연출 전용 EGO 장비
206011  허환경               홍루 연출 전용 EGO 장비
211011  토 파토스 마토스      오티스 연출 전용 EGO 장비
```

영문이 정체를 밝힌다 — **"Battle Cinematic Exclusive E.G.O"**.

### id 가 6자리다

```
20101  →  201011        기본 E.G.O id + 1
20301  →  203011
20501  →  205011
20601  →  206011
21101  →  211011
```

원본 5건이 **전부 `slotId: 1` 기본 ZAYIN** 이다. 전투 컷신에서 쓰는 복제 개체이며
`egos.json` · `ego-details` 어디에도 없다.

> **E.G.O id 는 5자리가 아니다.** 로케일 파일에 6자리가 섞여 있다. 자릿수로 파싱하면 깨진다.

`a1c9p3` 는 1막 9장 3부 시점의 델타다. 인격 편 회차 11–13에서 본 것과 같은 명명이며,
**본편 파일을 덮어쓰지 않고 추가만 한다.**

**적재** — 하지 않는다. 실제 장비가 아니다.
