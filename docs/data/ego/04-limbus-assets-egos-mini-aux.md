`shared-library` 에만 있는 항목은 **0건**이다.

### 없는 5건이 전부 최신이다

| id | E.G.O | 출시일 | 시즌 |

| `21009` | 하모니 (싱클레어) | 2026-03-05 | 9108 |

**`shared-library` 스냅샷은 2026-03-05 직전에 멈춰 있다.** 인격 편 회차 7에서 본 것과
같은 성격이며, 여기서는 시점이 더 정확히 잡힌다.

### 변화는 단조 증가다

105건 공통분에서 값이 다른 것은 두 축뿐이다.

| 키 | 다른 건수 |
| --- | ---: |
| `statuses` | **14** |
| `date` | **1** |
| 나머지 8종 | 0 |

`statuses` 는 **22개 추가 · 0개 제거**다. 빠진 것이 하나도 없다.

```
추가 최빈   VibrationExplosion 7 · SuperCoin 3 · Vibration 2 …
```

`VibrationExplosion`(진동 폭발)이 압도적이다 — 상태 정의가 세분화되면서 기존 E.G.O 의
목록이 보강된 것으로 보인다. **`statuses` 는 완결된 목록이 아니라 계속 채워지는 축이다.**

### `20306` 전기울음 날짜 — 오타의 시간축이 드러났다

인격 편 회차 1에서 「mj 연도 오타」로 기록한 건이다. **서술을 다듬어야 한다.**

```
mj            2023-04-11      ← 오타
shared(구)    2023-04-11      ← 같은 오타
assets(현)    2024-04-11      ← 정정됨
```

두 출처가 같은 값을 갖고 현행 assets 만 다르다. **mj 만의 오타가 아니라
원본에 있던 오타를 `limbus-assets` 가 나중에 고친 것**이다.

정정 방향이 맞다는 근거는 같은 날 나온 짝들이다.

| id | E.G.O | assets | shared |
| --- | --- | --- | --- |
| `20306` | **전기울음 (돈키호테)** | 2024-04-11 | **2023-04-11** |
| `20506` | 전기울음 (뫼르소) | 2024-04-11 | 2024-04-11 |
| `20706` | 구속 (히스클리프) | 2024-04-11 | 2024-04-11 |
| `21106` | 구속 (오티스) | 2024-04-11 | 2024-04-11 |

**같은 날 4종이 나왔고 그중 하나만 연도가 달랐다.** 시즌 4 전체가 2024년인 것과 함께
`2024-04-11` 이 맞다.

### mini 의 차이 29건도 같은 이야기다

`shared-library/egos_mini.json` 은 서브키 5종뿐이다(`affinity`·`name`·`rank`·`season`·`sinnerId`).
차이 29건은 전부 **`extractable` 28 + `maxThreadspin` 3 이 나중에 추가된 것**이다
(겹치는 2건 제외).

회차 3에서 `extractable` 이 도구 필드임을 확인했는데, **구버전에 키 자체가 없다는 사실이
이를 뒷받침한다** — 게임 데이터라면 처음부터 있었을 것이다.

1. `egos_mini.json` 의 `affinity` 는 **각성 값뿐**이다. 침식은 통째로 빠져 있다

5. `statuses` 는 **완결되지 않는다.** 구버전 대비 22개가 늘었고 줄어든 건 0이다
