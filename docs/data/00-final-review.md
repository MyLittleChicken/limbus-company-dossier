## 1. 무엇을 세었나

51회차 동안 각 원본 파일의 **모든 키**를 실측하고, 같은 개념을 여러 출처가 가질 때
어느 쪽이 무엇을 갖는지 장부에 적었다. 「개념」은 **필드가 아니라 뜻**의 단위다.

```
인격 14 · E.G.O 9 · 기프트 8 · 팩 4 · 거울 던전 7 · 상태 5 · 인카운터 3   =  51회차
```

「단독 보유」는 **그 출처가 없으면 그 뜻을 어디서도 얻지 못하는 것**을 뜻한다.
같은 값을 여러 곳이 갖는 중복은 세지 않았다.

## 5. 출처별 신뢰 프로파일

51회차가 그린 각 출처의 성격이다. **업데이트 대응의 핵심 자료**다.

### `limbus-data-mj` — 정확하지만 갱신이 늦다

```
강함    한국어 인라인 · 구조화된 조건(requires) · 색 원본 · 맵 생성 규칙
        기프트 목록 · 층 배정 · 델타 방식(값이 바뀐 단계만 기록)
약함    갱신 누락       hardOnly 69 · uniquePacks 59 · 이벤트 테마 기프트 122
        규모           기프트 441 (assets 456) · E.G.O 스킬 208 (assets 210)
```

**표현력의 한계로 못 담는 것**도 있다 — `9083` 달의 기억의 대체 슬롯 레시피,
`20608`·`21209` 의 두 번째 각성 스킬.

### `limbus-assets` — 넓지만 되바꾸기에서 실수한다

```
강함    수치 전량(baseValue·coinValue) · 상태 축 · 애셋 · 엔진 어휘(triggers)
        완전집합 성향 (기프트 456 · E.G.O 스킬 210)
약함    되바꾸기       affinity 4건 (색 → 죄악 실패)
        갱신 누락      hardOnly 6 · uniquePacks 0
        도구 오염      extractable · notes · 추천 묶음 · tips  ← 게임 데이터와 섞여 있다
```

**도구 도메인 필드 4종**을 게임 데이터와 같은 트리에 둔다. 층을 구분해 읽어야 한다.
다만 `extractable` 은 값 자체가 게임과 일치함을 게임 확인으로 밝혔다.

### `loc-ko/en/ja` — 한국어의 유일 출처

```
강함    한국어 표시 문자열 전반 · 유래 환상체(abName) · 키워드 공식 사전
        연출 전용 개체 · 획득 조건 문구
약함    결손          상태 245종 · 기프트 6건 · loc-ko 에 EGOgift.json 없음
        비대칭        로케일마다 파일 목록이 다르다 (거울 던전 50·51·53)
        원본 버그     undefined 키 1,653건 · BOM 4파일
```

### `shared-library` — 시간축

```
쓰임    구버전 스냅샷. 삭제된 것을 회수하고 필드가 언제 붙었는지 알려준다
        인격 편에서 삭제 스킬 6건 회수 · assets 가 affinity·effects·triggers 를
        나중에 얻었음을 확인
주의    id 체계가 파일마다 다르다 — 팩은 "C1-1", 층별 팩은 숫자
        애셋만 .png (현행은 .webp)
```

## 7. 그래서 무엇을 해야 하나

### 7.1 초기 DB — 합집합으로 세운다

```
척추       인격 mj · E.G.O assets · 기프트 assets · 팩 mj · 상태 assets
보강       각 편 장부의 「단독 보유」 열
한국어     loc-* 우선, terms.json 이 메우고, 245종은 영문 폴백
```

**지금 파이프라인이 이미 이 구조**다. 마스터북은 그것이 옳았음을 확인하고
**빠진 곳 7건을 특정**했다.

### 7.2 바로 고칠 것 — 백로그 7건

| # | 내용 | 근거 |
| ---: | --- | --- |
| 01 | `affiliation` → `trait` 개명 | 인격 1 |
| 06 | `atkTypes` 세 곳 다른 단위 | 인격 1 |
| 07 | 변환 리포트를 `build/report.json` 으로 | 인격 전반 |
| **08** | **`hardOnly` 합집합 적재** — 6건 누락 | 기프트 1 · **판정 완료** |
| 09 | `Pack` 모델 추가 — 이름조차 없다 | 팩 1–4 |
| 10 | 인카운터 연결표 없음 | 인카운터 2 |
| 11 | 시즌 레이블 (`S9104` · `S8000`) | 인격 1 · E.G.O 1 |

**08 은 게임 확인까지 끝나 바로 구현 가능**하다.

### 7.3 업데이트 대응 — 어디를 보면 되나

다음 스냅샷에서 **출처별로 볼 곳이 다르다.**

```
mj      새 콘텐츠가 늦게 들어온다      →  건수 차이부터 본다 (441 vs 456)
assets  색·불리언 되바꾸기가 샌다      →  attributeType ↔ affinity · hardOnly 대조
loc     파일 목록이 흔들린다          →  로케일 간 파일 diff 부터
전부     완전 일치 쌍 7건이 깨지면     →  그것이 곧 회귀 신호
```

**4.1 의 완전 일치 쌍 7건을 `src/verify.ts` 검사로 옮기면** 다음 갱신에서
자동으로 어긋남을 잡는다. 지금은 사람이 회차마다 돌린 프로브다.
