## 7. 검증 과정에서 나온 갭의 규명

1차 검증에서 6건이 갭으로 보고되었다. 전수 조사한 결과 **5건은 검증 방식의 오류**였다.

| 최초 보고 | 규명 결과 |
| --- | --- |
| 인격 상세 2건 누락 (`9999`, `40501`) | **오류.** `9999`는 NPC 베르길리우스, `40501`은 뫼르소 외형(Façade) 아이템. 둘 다 편성 가능한 인격이 아니다. 실제 인격 집합은 184가 맞다 |
| 기프트 이미지 724건 누락 | **오류.** 애셋 파일명이 id가 아니라 게임 내부 스프라이트 키(`srcPath`) 기준이다. 456종 중 75종만 `srcPath`가 숫자라 id 매칭이 대부분 실패했다. 이름으로 재매칭하니 **456/456 전수 확보**. 상세는 `data/README.md` |
| 기프트 합집합 799 대비 부족 | **오류.** 로컬라이즈 파일은 스토리 던전·이벤트 등 **모든** E.G.O 기프트를 담는다. 거울 던전 기프트는 456이 전부다 |
| 한국어 기프트 6건 미확보 | **오류.** 해당 6건은 거울 던전 기프트가 아니다(limbus-assets 목록에 0/6) |
| 상태 이미지 254건 누락 | **오류.** 미매칭 254건은 전부 `srcPath`가 없는 항목, 즉 게임에 아이콘이 존재하지 않는 수치 변화형 상태다 |
| 스킬 아이콘 221건 누락 | **부분 사실.** 208건은 E.G.O 스킬로 별도 아이콘 없이 E.G.O 이미지를 쓴다. 나머지 **13건이 실제 누락**이다 |

### 실제 누락: 인격 스킬 아이콘 13건

`1000104`(E.G.O 침식) 외 12건이며, 대부분 이름이 없는 반격·조건부 발동 스킬이다.
게임에서 기본 스킬 아이콘을 공유하는 것으로 보이나 확정하지 못했다.
정보 제공 화면에서 이 스킬들을 노출할 경우 대체 아이콘이 필요하다.

## 9. 검증 방법과 재현

- 전체 JSON 9,846개 파싱 성공, 실패 0. BOM 포함 29개는 제거 후 파싱한다.
- `data/manifest.json`에 파일별 SHA-256과 출처 커밋이 있다. 커밋 해시로 동일 스냅샷을 재현할 수 있다.
- `data/coverage.json`에 엔티티·애셋·다국어 커버리지 수치가 기계 판독 가능한 형태로 있다.

## 10. 이 문서가 보증하는 범위

**보증하는 것** — 2026-07-25 시점에 공개 접근 가능한 경로로 확보할 수 있는 거울 던전 관련 데이터를 전수 수집했고,
독립된 출처 간 대조로 엔티티 집합이 일치함을 확인했다.

**보증하지 않는 것** — 게임 클라이언트와 직접 대조하지 않았다. 상류 저장소가 게임에서 정확히 추출했다는 전제 위에 있다.
따라서 이 문서는 *"수집 가능한 것을 다 수집했다"* 의 근거이지, *"게임의 모든 데이터와 일치한다"* 의 증명은 아니다.
후자를 위해서는 게임 설치 환경에서의 직접 덤프가 필요하며, 현재 범위 밖이다.
